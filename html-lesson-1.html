Your First HTML Page 🚀

Welcome to your first coding lesson! Learn how websites display headings, paragraphs and text.

1. What is HTML?

HTML stands for HyperText Markup Language. It tells a web browser how to structure a webpage.

Here are three important HTML elements:

  • <h1> — creates a main heading.
  • <p> — creates a paragraph.
  • <button> — creates a clickable button.

2. Your first example

<h1>Hello World!</h1>
<p>I am learning HTML.</p>

The browser displays a heading followed by a paragraph. Try changing the text in the coding editor below.
